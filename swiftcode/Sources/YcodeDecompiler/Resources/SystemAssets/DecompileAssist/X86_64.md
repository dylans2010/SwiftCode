# x86-64 Reference

x86-64 (AMD64) powers Intel/AMD Macs (pre-Apple-Silicon), Windows, Linux,
and most servers. It is a CISC architecture: variable-length instructions,
rich addressing modes, and flags-based conditionals.

## Instruction traits

- **Variable-length 1–15 byte instructions**, little-endian. Instruction
  boundaries are ambiguous in raw data — disassembly must start at a known
  good offset (function entry or branch target), which is why function
  discovery matters.
- **16 GPRs**: `rax rbx rcx rdx rsi rdi rbp rsp r8–r15`. 32-bit ops use the
  `e` prefix (`eax`), 8-bit the `*l`/`*h`/`spl`–`r15b` forms.
- **System V ABI** (Linux/macOS): args in `rdi rsi rdx rcx r8 r9`, return in
  `rax`/`rdx`; stack args after 6. **Windows x64 ABI**: args in `rcx rdx r8
  r9` + stack, shadow space, return in `rax`.
- **RFLAGS** carry condition codes; `cmp`/`test` set them, `jcc`
  (`je/jne/jl/jg/ja/…`) consume them. `setcc` materializes them.
- **RIP-relative addressing**: `[rip+disp32]` reaches globals/strings —
  the x86-64 analogue of ARM64's `adrp+add`. One instruction, one target.

## Common patterns to recognize

- `push rbp; mov rbp, rsp; …; leave; ret` or `sub rsp, N; …; add rsp, N; ret`:
  classic frame setup/teardown.
- `call` pushes return address; `jmp` tail-calls reuse the frame — a `jmp`
  to another function at the end of a function is often a sibling call.
- `endbr64` at function entries: CET indirect-branch marker (Windows and
  newer macOS). Its presence/absence hints at compiled-with-CET code.
- `mov rax, [rip+X]` / `lea rdi, [rip+X]`: global/string references.
- `rep movsb`/`rep stosb`: inline memcpy/memset idioms.
- `ud2`: deliberate trap — assertion failure, `__builtin_trap`, unreachable.
- `int3`/`0xCC`: breakpoint padding between functions.

## SSE/AVX

- `movaps/movups/movdqa` and arithmetic on `xmm`/`ymm`/`zmm` registers:
  vectorized code — loops over arrays, crypto, media. Pseudocode usually
  renders these as scalar-looking loops; check assembly when vectorization
  matters.
- `vzeroupper` before calls: AVX→SSE transition penalty avoidance.

## Reading decompiled x86-64

- Stack variables appear as `[rbp-X]`/`[rsp+X]`; decompilers name them
  `local_X`/`param_X`. Tracking which slot is which argument requires the
  ABI and the prologue.
- Flags idioms (`cmp` + `setcc` + `movzx`) become boolean expressions.
- Switch tables: `jmp qword ptr [rip+rax*8+table]` or bounds-checked index
  into a table of addresses — the CFG shows an indirect branch; the table
  itself is data (`inspect_memory_region` on the table address lists cases).
