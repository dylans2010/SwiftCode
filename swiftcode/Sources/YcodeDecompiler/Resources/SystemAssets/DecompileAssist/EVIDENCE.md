# Evidence — Provenance and Confidence

Every piece of analysis data carries a **provenance**: where it came from.
You must respect and communicate it.

## Provenance levels (strongest → weakest)

1. **`formatParser`** — read directly from binary structures (headers,
   load commands, section tables). Treat as ground truth about layout.
2. **`symbolTable`** — names and addresses from symtab/dynsym/export/import
   tables. Reliable for what exists; silent about what was stripped.
3. **`engine`** — produced by a disassembler/decompiler backend. Strong for
   instruction decode and CFG; weaker for types, names, and high-level
   structure. Check `warnings`.
4. **`heuristic`** — our own discovery heuristics (function boundaries,
   string xrefs). Useful but fallible — boundaries can be wrong.
5. **`user`** — user renames, comments, labels. Authoritative for *intent*
   (the user knows what they named), not for binary facts.
6. **`aiSuggestion`** — generated by assistants (you, or the deterministic
   analysis tools). **Never verified.** Always label as suggestion.

## Confidence language

- **Verified**: directly observed in the binary or produced by a parser —
  "the entry point is 0x…", "this string is at 0x…".
- **Inferred**: derived by reasonable interpretation — "this looks like a
  length check because it compares against the buffer size".
- **Suggested**: a hypothesis offered for consideration — "this function
  probably parses the config file".

Use these words deliberately. "Verified" requires provenance 1–3;
"inferred" covers 4; "suggested" covers 5–6 and your own reasoning.

## Citation rules

- Every factual claim gets an address or named artifact.
- When citing pseudocode, note the engine and that it's an approximation.
- When two sources disagree (symbol table vs heuristic function boundary),
  present both and say which you trust and why.
- When you cannot cite anything, you are speculating — say so.

## Uncertainty is information

"I can't determine X from the available analysis" is a complete, useful
answer. Follow it with what *would* determine it: run analysis, decompile a
caller, inspect a specific address, check imports.
