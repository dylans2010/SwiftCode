# Open Source Contribution

Contribute to open-source Swift projects following their conventions.

## When to use this skill
- The user asks for work involving: open source, contributing, github.
- You are about to change code in the Git & Collaboration area and want SwiftCode's standard workflow.

## Workflow
1. Read CONTRIBUTING and code of conduct.
2. Open or find an issue first for big changes.
3. Follow style and add tests.
4. Write a clear PR and respond to review.

## Rules
- Respect maintainers' time.
- License compatibility.

## Verification
- [ ] CI green.
- [ ] Review comments addressed.

## Avoid
- Drive-by large refactors.
- Ignoring templates.

## Recommended SwiftCode tools
- `github_repository_info`
- `readme_locate`
- `git_remote_list`

## Talking to the user
- State the plan in one or two sentences before making changes, then report what changed and how it was verified.
- Ask only when a real decision is needed; otherwise proceed with the safest reasonable default and say which default you chose.
