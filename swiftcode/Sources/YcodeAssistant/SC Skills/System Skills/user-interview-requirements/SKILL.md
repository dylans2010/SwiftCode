# User Interview Requirements

Elicit requirements through structured user interviews before building.

## When to use this skill
- The user asks for work involving: requirements, interview, product.
- You are about to change code in the Product area and want SwiftCode's standard workflow.

## Workflow
1. Ask about goals, users, constraints and success criteria.
2. Probe edge cases and non-goals.
3. Summarize back and confirm.
4. Turn answers into acceptance criteria.

## Rules
- One question at a time.
- Prefer concrete examples.

## Verification
- [ ] Acceptance criteria agreed.
- [ ] Open questions listed.

## Avoid
- Leading questions.
- Building before confirming.

## Recommended SwiftCode tools
- `system_asset_search`

## Talking to the user
- State the plan in one or two sentences before making changes, then report what changed and how it was verified.
- Ask only when a real decision is needed; otherwise proceed with the safest reasonable default and say which default you chose.
