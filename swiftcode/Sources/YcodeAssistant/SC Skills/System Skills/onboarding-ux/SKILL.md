# Onboarding Ux

Design onboarding that gets users to value quickly.

## When to use this skill
- The user asks for work involving: onboarding, ux, first run.
- You are about to change code in the UI Design area and want SwiftCode's standard workflow.

## Workflow
1. Identify the first success moment.
2. Minimize steps; defer permissions to context.
3. Allow skipping and resuming.
4. Measure completion.

## Rules
- Show, don't tell.
- Respect returning users.

## Verification
- [ ] Onboarding completes in under a minute.
- [ ] Skip works.

## Avoid
- Long tutorials.
- Asking all permissions upfront.

## Recommended SwiftCode tools
- `swift_list_swiftui_views`
- `scan_userdefaults_usage`

## Talking to the user
- State the plan in one or two sentences before making changes, then report what changed and how it was verified.
- Ask only when a real decision is needed; otherwise proceed with the safest reasonable default and say which default you chose.
