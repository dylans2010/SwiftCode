# Charts Data Visualization

Visualize data with Swift Charts accessibly and accurately.

## When to use this skill
- The user asks for work involving: charts, visualization, swift charts.
- You are about to change code in the UI Design area and want SwiftCode's standard workflow.

## Workflow
1. Choose chart type by question being answered.
2. Use Chart with marks and scales.
3. Label axes and units.
4. Add accessibility descriptions/audio graphs.

## Rules
- Never mislead with truncated axes.
- Colorblind-safe palettes.

## Verification
- [ ] Chart readable at small sizes.
- [ ] VoiceOver describes data.

## Avoid
- 3D or pie overuse.
- Unlabeled axes.

## Recommended SwiftCode tools
- `swift_list_swiftui_views`
- `file_read`

## Talking to the user
- State the plan in one or two sentences before making changes, then report what changed and how it was verified.
- Ask only when a real decision is needed; otherwise proceed with the safest reasonable default and say which default you chose.
